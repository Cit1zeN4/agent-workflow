# Domain docs

This repository uses a single domain context.

Before work in a domain area, read the root `GLOSSARY.md` if it
exists and the relevant ADRs in `docs/adr/`. If absent, continue;
create them when terminology or decisions need recording.

Use glossary terms in issues, code proposals and tests. Surface
conflicts with an existing ADR explicitly instead of silently
replacing its decision.

Layout: root `GLOSSARY.md`; system decisions in `docs/adr/`.

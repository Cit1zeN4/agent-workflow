# 10.01. Проекты и настройка

> Статус: план реализации; код и проверки не выполнялись.

## Цель

Дать пользователю подключить проект и пройти настройку скиллов через браузер.

## Зависимости и границы

**Зависимости:** 01, 05, 07, 08.02.

Входит: список проектов, форма подключения, статус настройки и вопросы setup. Не входит: реализация проверки Git-пути и логика setup.

## Последовательность реализации

1. Показать список сохранённых проектов и форму подключения через локальный API.
2. Вывести ошибки валидации пути и состояние Git без передачи браузеру произвольных системных команд.
3. Показать состояние настройки скиллов и разрешить явный запуск или повтор.
4. Отобразить ожидающие HITL-запросы setup через общий UI этапа 10.03.

## Тестовые сценарии

- Некорректный путь даёт понятную ошибку.
- Успешный проект остаётся виден после обновления страницы.
- Повторный run не навязывает повтор setup.

## Критерии приёмки

- [ ] Проект подключается и выбирается без терминала Codex.
- [ ] Статус настройки отражает сохранённое состояние.
- [ ] UI использует локальный API.

Для закрытия критериев нужны результаты проверок; наличие плана не означает приёмку.

# 09.04. Git-изменения и проверки

> Статус: план реализации; код и проверки не выполнялись.

## Цель

Сохранять проверяемые diff, результаты проверок и сведения о commits для ticket.

## Зависимости и границы

**Зависимости:** 07, 08.04, 09.03.

Входит: снимки Git-состояния, результаты проверок и metadata commits. Не входит: создание worktree этапа 07, UI просмотра и автоматический merge.

## Последовательность реализации

1. Зафиксировать base commit и исходное состояние worktree до выполнения ticket.
2. После попытки собрать список изменённых файлов, diff и рабочую ветку; связать их с ticket и execution.
3. Записать команды и итоги предусмотренных проверок без произвольной команды из браузера.
4. Если commit создан, сохранить hash и metadata; если нет — явно отметить отсутствие.
5. Не считать успешным ticket с неразобранными ошибками проверок.

## Тестовые сценарии

- Изменения ticket видны в diff и не затрагивают основную копию.
- Неудачная проверка сохраняет вывод и блокирует успех.
- Отсутствующий commit не маскируется фиктивным hash.

## Критерии приёмки

- [ ] История ticket содержит diff, проверки и commit metadata при наличии.
- [ ] Пути и ветки сверены с разрешённым worktree.
- [ ] Результат проверок влияет на итог ticket.

Для закрытия критериев нужны результаты проверок; наличие плана не означает приёмку.

## Ожидаемые артефакты

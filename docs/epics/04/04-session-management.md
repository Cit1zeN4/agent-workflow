# 04. Session Management

## Цель

Управлять жизненным циклом сессий Codex и связывать их с этапами и отдельными tickets.

## Содержание

- Сопоставить workflow run, agent session и agent execution, сохраняя runtime identifiers.
- Поддержать общую сессию для связанных этапов и независимую сессию для ticket.
- Передавать нужный контекст при создании и продолжении session.
- Обрабатывать потерю session и невозможность продолжения thread.

## Критерии приёмки

- Два последовательных связанных этапа могут использовать один thread, а два отдельных tickets получают разные session identifiers.
- После перезапуска сохранённые идентификаторы позволяют продолжить поддерживаемую runtime сессию.
- Если продолжение невозможно, execution не выдаётся за успешно восстановленный: записывается причина и предлагается безопасный повтор с контекстом.
- История executions одной session доступна в порядке создания.

**Зависимости:** 02, 03. **Результат:** Session Manager и политика продолжения.

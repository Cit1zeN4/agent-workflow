# 01. Project Foundation

## Цель

Заложить работающий каркас локального приложения для Windows и согласовать контракты между основными модулями.

## Содержание

- Создать проекты React + TypeScript и Node.js + TypeScript с едиными командами запуска, сборки и проверки.
- Описать границы Workflow Engine, Session Manager, HITL Manager, Agent Runtime Adapter, Project Manager и Persistence Layer.
- Ввести типизированные модели проекта, workflow run, этапа, execution, session, события и пользовательского запроса.
- Поднять локальный API и минимальную страницу проверки доступности; задокументировать запуск и версии окружения.

## Критерии приёмки

- На Windows приложение запускается локально по инструкции; UI получает ответ от backend без ручного изменения исходников.
- Команды сборки и автоматических проверок завершаются успешно в чистой копии проекта.
- Контракты явно различают workflow run, agent session и agent execution; зависимости модулей не образуют циклов.
- API слушает только локальный интерфейс и не предоставляет браузеру произвольное выполнение команд.

**Зависимости:** нет. **Результат:** исходный каркас, контракты и инструкция запуска.

# 01.04. Проверки и инструкция Windows

> Статус: план реализации; команды и версия окружения требуют фактического запуска.

## Цель

Сделать каркас этапа 01 воспроизводимым для следующего исполнителя на Windows.

## Зависимости и границы

**Зависимости:** 01.01–01.03. Входит: автоматическая проверка каркаса, инструкция установки и запуска, запись окружения. Не входит: совместимость Codex этапа 02 и полный E2E этапа 12.

## Последовательность реализации

1. Собрать в одном месте команды установки, запуска frontend/backend, проверок и сборки.
2. Добавить минимальный smoke проверки API и связи UI с backend; проверять реальный процесс, а не только исходный код.
3. Выполнить команды в чистой копии на Windows, записать версии Node.js и ОС, фактический результат и известные ограничения.
4. Описать типовые ошибки старта: занятый порт, отсутствие инструмента, недоступный backend.

## Тестовые сценарии

| Сценарий | Ожидаемый результат |
|---|---|
| Новый исполнитель следует инструкции | Запускает UI и получает ответ backend. |
| Команды проверок после чистой установки | Завершаются с ожидаемым кодом. |
| Занятый порт | Ошибка объяснима и не выдаётся за успешный запуск. |

## Критерии приёмки

- [ ] Инструкция воспроизводится на Windows без ручной модификации исходников.
- [ ] Все обязательные команды имеют фактический результат проверки.
- [ ] Версии и ограничения отделены от целевых значений проекта.

## Ожидаемые артефакты

Runbook, результаты smoke и список проверенных версий окружения.

## Открытые вопросы и проверки

Итоговая установка и упаковка будут определены в 12; здесь нужен только путь разработчика.

# 07. Project & Workspace Management

## Цель

Безопасно подключать локальные Git-проекты и готовить изолированные рабочие каталоги для runs.

## Содержание

- Проверять путь, наличие Git-репозитория, доступность файлов и исходное состояние проекта.
- Сохранять конфигурацию и показывать список подключённых проектов.
- Создавать worktree и рабочую ветку, связывать их с run или ticket.
- Определить допустимые пути, права доступа и безопасную очистку ресурсов.

## Критерии приёмки

- Корректный репозиторий подключается и после перезапуска остаётся в списке; ошибочный путь получает объяснимый отказ.
- Рабочий каталог и ветка создаются без изменения основной ветки; повторное создание не повреждает существующий worktree.
- Изменения внутри worktree видны как Git diff и не затрагивают исходную рабочую копию.
- Операции с путями ограничены выбранным проектом; worktree не считается security sandbox для команд агента.

**Зависимости:** 01, 03. **Результат:** Project Manager и изолированные Git worktrees.

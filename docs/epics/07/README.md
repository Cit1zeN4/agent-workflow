# Этап 07 — Project & Workspace Management

Пять самостоятельных заданий на реализацию. Основание: [исходный эпик](07-project-and-workspace-management.md) и [требования проекта](../../project.md). Это план; Git-операции и ограничения путей предстоит проверить на целевой Windows-конфигурации.

| Подэтап | Задание |
|---|---|
| 07.01 | [Проверка локального проекта](07.01-repository-validation.md) |
| 07.02 | [Конфигурация проекта](07.02-project-configuration.md) |
| 07.03 | [Границы путей и доступа](07.03-path-boundaries.md) |
| 07.04 | [Ветка и Git worktree](07.04-worktree-lifecycle.md) |
| 07.05 | [Освобождение ресурсов и проверки](07.05-cleanup-and-tests.md) |

Порядок: сначала проверка и сохранение проекта, затем политика путей, после неё создание worktree; в конце очистка и интеграционные проверки. Черновик правил путей нужен до первого файлового действия.

Границы: этап 07 выбирает, проверяет и подготавливает локальный workspace. Этап 02 получает явный cwd; 06 управляет run; 09 выполняет tickets, хранит их Git-результаты и правила push/merge. Этап 07 не является sandbox команд агента и не даёт браузеру произвольного доступа к файловой системе.

Каждый критерий принимается по тестам и фактическим Git-результатам. Наличие плана не доказывает безопасность или совместимость с Windows.

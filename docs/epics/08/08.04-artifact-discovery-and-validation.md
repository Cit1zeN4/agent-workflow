# 08.04. Поиск и проверка артефактов

> Статус: план реализации; код и проверки не выполнялись.

## Цель

Находить и проверять результаты скиллов отдельно от статуса Codex turn.

## Зависимости и границы

**Зависимости:** 06, 07, 08.01, 08.03.

Входит: привязка файлов к execution, проверки наличия и структуры. Не входит: бизнес-переходы этапа 06 и чтение графа tickets этапа 09.

## Последовательность реализации

1. Зафиксировать наблюдаемые типы и допустимые пути результатов по 08.01.
2. Сравнивать состояние workspace до и после вызова, сохраняя созданные и изменённые артефакты.
3. Проверять наличие, непустое содержимое и нужную структуру; tracker проверять только по подтверждённому формату.
4. Передавать Workflow Engine результат с причиной отказа и ссылками на файлы.

## Тестовые сценарии

- Completed turn без файла не завершает этап.
- Пустая спецификация получает конкретную ошибку.
- Файл вне workspace не принимается.

## Критерии приёмки

- [ ] Успешный результат подтверждён артефактом.
- [ ] Пустой и неполный результат блокирует переход.
- [ ] Артефакт связан с этапом и execution.

Для закрытия критериев нужны результаты проверок; наличие плана не означает приёмку.

## Ожидаемые артефакты

Валидаторы, каталог типов артефактов и отчёты проверки.

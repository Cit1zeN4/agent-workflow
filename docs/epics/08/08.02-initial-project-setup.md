# 08.02. Первоначальная настройка проекта

> Статус: план реализации; код и проверки не выполнялись.

## Цель

Выполнить `/setup-matt-pocock-skills` для проекта и сохранить подтверждённый результат.

## Зависимости и границы

**Зависимости:** 07, 05, 08.01.

Входит: состояние настройки, запуск, ответы HITL и проверка результата. Не входит: общая политика HITL этапа 05 и экраны этапа 10.

## Последовательность реализации

1. Определить состояния настройки и связать их с версией скиллов и проектом.
2. Запускать setup в выбранном workspace; вопросы передавать через HITL.
3. После turn проверять признаки результата из 08.01; сохранять артефакты и попытки.
4. Повторную настройку делать явным действием при изменении версии или неуспехе.

## Тестовые сценарии

- Повторный run не повторяет успешный setup.
- Отказ пользователя сохраняется и не объявляется успехом.
- Completed turn без результата оставляет настройку незавершённой.

## Критерии приёмки

- [ ] Состояние настройки сохраняется между перезапусками.
- [ ] Вопросы проходят через HITL с защитой от повторного ответа.
- [ ] Готовность проекта основана на проверенном результате.

Для закрытия критериев нужны результаты проверок; наличие плана не означает приёмку.

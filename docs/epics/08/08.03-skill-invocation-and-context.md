# 08.03. Вызов скиллов и контекст

> Статус: план реализации; код и проверки не выполнялись.

## Цель

Задать входы скиллов и явную передачу контекста проекта и предыдущих этапов.

## Зависимости и границы

**Зависимости:** 04, 06, 07, 08.01.

Входит: контракт вызова, manifest входов, cwd и связь с execution. Не входит: переходы Workflow Engine, исполнение tickets и детали протокола Codex.

## Последовательность реализации

1. Для каждого скилла описать разрешённый этап, входные артефакты, cwd и session policy по результатам 08.01.
2. Собирать контекст из сохранённых документов и решений; фиксировать manifest входов.
3. Проверять обязательные входы и границы workspace до запуска turn.
4. Сохранять версию скиллов, manifest, execution и итог вызова.

## Тестовые сценарии

- Отсутствующая spec блокирует `/to-tickets`.
- Связанный этап получает проверенные артефакты предыдущего.
- Путь вне workspace отклоняется до вызова.

## Критерии приёмки

- [ ] Каждый вызов имеет явные входы и допустимый рабочий каталог.
- [ ] Вызов воспроизводим по manifest без секретов.
- [ ] Отсутствующий вход даёт понятный отказ.

Для закрытия критериев нужны результаты проверок; наличие плана не означает приёмку.

## Ожидаемые артефакты

Контракт вызова, manifest контекста и журнал запусков.

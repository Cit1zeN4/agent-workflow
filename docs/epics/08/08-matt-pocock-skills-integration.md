# 08. Matt Pocock Skills Integration

## Цель

Запускать предусмотренные скиллы с контекстом проекта и проверять их реальные результаты.

## Содержание

- Реализовать первоначальную настройку `/setup-matt-pocock-skills` с вопросами в UI.
- Описать вход, ожидаемые артефакты и критерий завершения каждого скилла workflow.
- Передавать документацию, решения и результаты предыдущих этапов в следующие вызовы.
- Проверить формат локального tracker и поведение интерактивных скиллов на реальной установке.

## Критерии приёмки

- Настройка выполняется в тестовом репозитории, фиксирует результат и не требуется повторно для каждого run.
- Каждый скилл запускается с нужным контекстом; созданные артефакты обнаруживаются и связываются с этапом.
- Пустой, ошибочный или неполный результат не помечает бизнес-этап успешным.
- Вопросы скиллов проходят через HITL; зафиксированы поддерживаемые версии, проверенный формат tracker и известные ограничения.

**Зависимости:** 02, 04–07. **Результат:** адаптер скиллов, валидаторы артефактов и проверенная настройка.

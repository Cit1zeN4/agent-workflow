# 02. Codex Runtime Integration

## Цель

Обеспечить управляемый обмен с локальным Codex App Server через JSON-RPC/stdin-stdout.

## Содержание

- Запускать и завершать процесс runtime, вести обмен сообщениями и коррелировать запросы с ответами.
- Создавать threads, запускать turns, получать структурированные события, ошибки и результаты.
- Реализовать прерывание выполнения и обработку неожиданного завершения процесса.
- Зафиксировать проверенную версию Codex и изолировать детали протокола в адаптере.

## Критерии приёмки

- Интеграционный сценарий с установленным Codex создаёт thread, выполняет turn и передаёт события вызывающему модулю в правильном порядке.
- Ошибка запуска, некорректный ответ и завершение процесса отражаются типизированным результатом; зависшие запросы получают конечное состояние.
- Прерывание активного turn подтверждается runtime либо явно помечается как неопределённый исход.
- Совместимость с фактически используемой версией проверена автоматизированным smoke test; при несовместимости выводится понятная диагностика.

**Зависимости:** 01. **Результат:** адаптер Codex и проверка протокола.

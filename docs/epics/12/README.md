## Порядок и границы

12.01 готовит среду; 12.02 и 12.03 проверяют продукт; 12.04 оформляет воспроизводимую поставку; 12.05 сопоставляет доказательства с критериями MVP. Сценарии компонентов остаются в 01–11, в особенности протокольный smoke 02.10 и fault injection 11.05. Здесь проверяется собранная система через локальный Web UI и установочный процесс.

Целевые номера версий из проекта не считаются проверенными только потому, что указаны в плане. Реальные проверки Codex могут требовать доступа к модели и явного запуска исполнителем; `blocked` и `not-run` не равны `pass`. Никакие push или merge не выполняются автоматически.

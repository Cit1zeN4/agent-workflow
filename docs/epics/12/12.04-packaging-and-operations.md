# 12.04. Поставка и инструкция

> Статус: план реализации; проверки не выполнялись.

## Цель

Сделать локальную установку, запуск, обновление и диагностику MVP воспроизводимыми на Windows.

## Зависимости и границы

**Зависимости:** 12.01–12.03. Входит: пакет или оформленный способ поставки, инструкции, проверка обновления. Не входит: облачный deployment и автоматический merge.

## Последовательность реализации

1. Выбрать минимальный формат локальной поставки, соответствующий фактической сборке React/Node.js, и описать необходимые внешние зависимости.
2. Подготовить команды установки и запуска с локальной привязкой API и проверкой доступности UI.
3. Документировать настройку Codex и Git без сохранения credentials в пакете; при отсутствии доступа выдавать понятную диагностику.
4. Описать обновление приложения и миграций SQLite с сохранением пользовательских данных; предусмотреть резервную копию перед изменением схемы.
5. Добавить инструкцию сбора диагностического отчёта без секретов и процедуру остановки локальных процессов.
6. Повторить установку и обновление из предыдущей поддерживаемой сборки в чистом Windows-окружении.

## Тестовые сценарии

| Сценарий | Ожидаемый результат |
|---|---|
| Чистая установка | UI и API запускаются по инструкции. |
| Обновление с существующей БД | Состояние и связи сохранены; миграции прошли. |
| Codex недоступен | Приложение объясняет причину без потери данных. |

## Критерии приёмки

- [ ] Другой исполнитель повторяет установку, запуск и остановку без правки исходников.
- [ ] Обновление сохраняет данные либо завершается с безопасной диагностикой и возможностью восстановления.
- [ ] Пакет и диагностический отчёт не содержат секретов.

## Ожидаемые артефакты

Пакет/команды поставки, инструкции пользователя и отчёт об установке/обновлении.

## Открытые вопросы

Формат пакета следует выбрать после появления фактической сборки, не закрепляя заранее установщик или service wrapper.

# 12. E2E Testing & Packaging

## Цель

Подтвердить готовность MVP на Windows и подготовить воспроизводимый локальный запуск.

## Содержание

- Автоматизировать основные сценарии и интеграционные проверки совместимости Codex, Node.js и Git for Windows.
- Пройти полный workflow в тестовом репозитории: настройка, вопросы, spec, tickets, утверждение, реализация, review, retro.
- Проверить безопасность, перезапуски, прерывания и ограничения локального API.
- Подготовить пакет/инструкцию установки, запуска, обновления и сбора диагностики.

## Критерии приёмки

- На Windows с зафиксированными проверенными версиями пользователь проходит полный сценарий через Web UI, включая два зависимых tickets, Git changes, code review и retrospective.
- Тест подтверждает работу реальных HITL-событий Codex, просмотр истории и артефактов, восстановление после перезапуска UI и безопасное поведение после сбоя backend/агента.
- Сборка и автоматические проверки проходят в чистом окружении; установка и запуск повторяются по инструкции.
- Зафиксированы результаты проверки, поддерживаемые версии и оставшиеся ограничения MVP; push/merge не происходят автоматически.

**Зависимости:** 01–11. **Результат:** проверенный локальный MVP и инструкция поставки.

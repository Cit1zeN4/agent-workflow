# 12.03. Сбои и границы безопасности

> Статус: план реализации; проверки не выполнялись.

## Цель

Проверить, что собранное приложение переживает сбои и соблюдает ограничения локального доступа.

## Зависимости и границы

**Зависимости:** 12.01, 11.05, готовый API/UI. Входит: сквозные проверки перезапусков, прерывания, доступа к API, путей и Git-действий. Не входит: повторение всех внутренних тестов компонентов.

## Последовательность реализации

1. Во время run обновить UI и разорвать SSE; проверить восстановление состояния из БД.
2. Во время активного execution прервать backend и runtime по отдельности; после рестарта проверить сверку и отсутствие автоматического повтора с неизвестным исходом.
3. При pending HITL запросе проверить отказ устаревшего ответа и явное дальнейшее действие.
4. Проверить привязку API к локальному интерфейсу, отклонение недопустимых путей и невозможность произвольного запуска команд через браузерный API.
5. Проверить, что операции в worktree не меняют основную рабочую копию и push/merge требуют отдельного разрешения.

## Тестовые сценарии

| Сценарий | Ожидаемый результат |
|---|---|
| Разрыв UI/SSE | Нет потери значимых событий и изменения run. |
| Сбой агента после действия с неизвестным исходом | Нет автоматического повтора; есть диагностируемый статус. |
| Путь за пределами выбранного проекта | Операция отклонена до изменения файлов. |

## Критерии приёмки

- [ ] Подтверждены критерии восстановления 13–14 из раздела 12 проекта.
- [ ] Локальный API и операции с файлами соблюдают ограничения NFR-03.
- [ ] Любой неопределённый исход виден пользователю и не запускает действие повторно.

## Ожидаемые артефакты

Сквозные сценарии сбоев и безопасности, обезличенные логи и результаты.

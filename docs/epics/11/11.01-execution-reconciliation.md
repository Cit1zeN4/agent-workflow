# 11.01. Сверка незавершённых executions

> Статус: план реализации; проверки не выполнялись.

## Цель

После запуска backend определить судьбу executions, которые в базе не имеют подтверждённого конечного состояния.

## Зависимости и границы

**Зависимости:** 02.09, 03, 04, 06, 09. Входит: снимок незавершённой работы, сверка журнала с runtime и фиксация результата. Не входит: повтор turn, повтор Git-действия и продолжение HITL-запроса.

## Последовательность реализации

1. Определить набор незавершённых состояний и сохранённые идентификаторы: run, stage, execution, session, runtime generation, thread, turn, последнее подтверждённое событие.
2. На старте получить согласованный снимок БД и пометить каждую запись как требующую сверки, не переводя её сразу в `failed` или `completed`.
3. Сопоставить журнал с возможностями фактически запущенного runtime. Отдельно учитывать недоступный runtime, смену generation, потерю thread и отсутствие подтверждённого terminal event.
4. Записать один из доказуемых результатов: подтверждённое завершение, подтверждённое прерывание либо требуется вмешательство с неизвестным исходом. Основание и время сверки сохранить событием.
5. Обеспечить повторяемый запуск процедуры: второй проход не создаёт новое execution и не меняет подтверждённое решение без новых доказательств.

## Тестовые сценарии

| Сценарий | Ожидаемый результат |
|---|---|
| Terminal event уже записан | Состояние восстанавливается без нового turn. |
| Процесс исчез до terminal event | Исход остаётся неизвестным до доказательств; автоматического повтора нет. |
| Сверка запущена дважды | Нет дубля перехода или события решения. |

## Критерии приёмки

- [ ] Каждый незавершённый execution получает проверяемый статус сверки и основание.
- [ ] Отсутствие runtime-доказательств не трактуется как провал или успех операции.
- [ ] Сверка повторяема и сохраняется атомарно с событием.

## Ожидаемые артефакты

Контракт сверки, реализация startup-процедуры и тесты с управляемыми сбоями.

## Открытые вопросы

Какие сведения о завершённом turn доступны после перезапуска в целевой версии Codex? До проверки ответ считать неизвестным.

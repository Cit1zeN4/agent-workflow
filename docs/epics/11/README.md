## Порядок и границы

11.01 задаёт состояния сверки, затем 11.02–11.04 реализуют решения для разных видов незавершённой работы; 11.05 проверяет их вместе. Контракты runtime и локальный `OutcomeUnknown` принадлежат 02, журнал и транзакции — 03, управление session — 04, ответы — 05, переходы workflow — 06. Этот этап связывает их после перезапуска и обеспечивает безопасный выбор дальнейшего действия.

Неизвестный исход не превращается в успех или разрешение на автоматический повтор. Возможность продолжить thread не означает возможность продолжить исходный активный turn или ожидающий запрос. Каждый критерий закрывается фактической проверкой, а не наличием плана.
